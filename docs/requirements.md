# 原価管理システム 要件サマリー

## 対象

- 1店舗で販売するタコス、カレー、コーヒー、アルコール、ソフトドリンク
- 仕込み原価を管理し、販売個数を基準に月単位で集計
- 金額は税込価格。入力は初版では手入力

## マスタ

- 商品: 商品名、カテゴリ、税込販売価格、使用材料、秘密レシピ非表示フラグ
- 材料: 材料名、使用量、単位、仕込みロス率
- 購入先・仕入: 購入先、税込価格、1ロット発注数、内容量、適用開始日
- ユーザー: Googleアカウント、表示名、管理者/一般、利用可否

## ダッシュボード

- 月間売上、トータル原価、平均原価率、販売個数
- 月別原価率、カテゴリ別売上、商品別原価・原価率
- 販売数は月単位で手入力でき、後から修正可能

## 権限

- 指定Googleアカウントのみログイン可能
- 管理者はマスタ、販売数、ユーザーを登録・更新可能
- 一般ユーザーは閲覧のみ。秘密レシピは非表示フラグがONの場合に表示しない
- 非表示フラグは後から変更可能。初版の既存商品はOFF（表示）

## 初版で追加推奨

- 仕入価格の履歴管理、原価再計算、入力検証、監査ログ
- CSV入出力、バックアップ、目標原価率アラート
- 原価計算時点のスナップショット保存
