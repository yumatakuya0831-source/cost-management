# 開発進捗・引継ぎ

## ワークフロー

1. `docs/progress.md` の現在フェーズと完了条件を確認する。
2. 実施内容、変更ファイル、判断と理由、未解決課題、検証結果を更新する。
3. 要件→設計→実装→テストの成果物リンクを保つ。
4. 失敗時は症状、原因、影響範囲、復旧・ロールバック手順を記録する。
5. 次担当へ「次に行うこと」「完了の判断基準」「注意事項」を明示する。

## 状態

各項目は `未着手`、`進行中`、`レビュー待ち`、`完了`、`保留` のいずれかとし、完了には証拠を添える。
