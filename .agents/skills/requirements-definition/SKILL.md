# 要件定義

## ワークフロー

1. `docs/ai_dev_skills_v2.yml` を参考資料として読み、ユーザーの最新指示を優先する。
2. 対象ユーザー、業務フロー、機能要件、非機能要件、権限、データ、制約を整理する。
3. 原価計算式、税込・税抜、仕込みロス、販売個数、対象期間を明文化する。
4. 未確定事項は推測で確定せず、「確認事項」として影響と選択肢を示す。
5. 各要件に検証可能な受入条件を付け、`docs/requirements.md` を更新する。

## 完了条件

- 管理者と一般ユーザーの表示・操作差が明確である。
- 社内秘レシピの非表示設定と初版の既定値が明記されている。
- Supabase、Google認証、単一店舗、月次集計の前提が反映されている。
- 設計担当が追加質問なしで設計を開始できる。
