# 品質・テスト

## ワークフロー

1. 要件の受入条件から正常系、境界値、異常系、権限系のテストを作る。
2. 税込価格、ロット、20人分、仕込みロス、販売個数、月次集計を数値で検証する。
3. 管理者、一般、未登録Googleアカウントで認証・認可を検証する。
4. 秘密レシピがUI、APIレスポンス、直接DBアクセスの全てで漏れないことを確認する。
5. lint、型、build、単体、統合、主要画面の表示を検証する。
6. `docs/test-report.md` に環境、手順、期待値、実績、不具合、再試験結果を残す。

## 判定

重大な権限漏れ、計算誤り、ビルド失敗が1件でもあればリリース不可とする。
